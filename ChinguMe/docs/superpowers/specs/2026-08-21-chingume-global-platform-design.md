# ChinguMe 글로벌 실시간 통역 소셜 플랫폼 마스터 기획서

- 문서 상태: 사용자 검토용 설계안
- 작성일: 2026-08-21
- 대상 제품: ChinguMe Friends, ChinguMe Dating, ChinguMe Opportunities
- 출시 원칙: 관리형 인프라로 빠르게 검증하고 핵심 미디어·AI를 단계적으로 자체화

## 1. 요약

ChinguMe는 한국과 세계의 성인이 언어 장벽 없이 친구, 연인, 여행 파트너, 프로젝트 동료와 일자리를 찾을 수 있도록 돕는 글로벌 프리미엄 소셜 플랫폼이다. 제품은 Friends와 Dating 두 개의 모바일 앱으로 제공하며, 회원·통역·미디어·안전·결제 기반은 하나의 공통 플랫폼으로 운영한다. Friends에는 만 18세 이상 전용 Opportunities 탭을 두어 관광 안내, 외주, 캐스팅, 구인구직을 지원한다.

일반회원은 자신의 OpenAI, Google, Azure Speech 또는 DeepL API 키를 연결해 AI 통역을 이용한다. 스페셜회원은 ChinguMe가 관리하는 OpenClaw 환경에서 로이 또는 지니 에이전트를 사용한다. 실시간 음성 처리는 지연시간에 최적화된 전용 ASR·번역·TTS 파이프라인이 담당하고, 로이·지니는 문맥, 말투, 문화적 의미, 통화 요약과 동의 기반 기억을 보조한다.

초기에는 관리형 WebRTC와 AI 서비스를 사용한다. 모든 외부 공급자는 ChinguMe가 소유한 Media API와 Translation Orchestrator 뒤에 배치하여 향후 자체 SFU·TURN·ASR·번역·TTS로 교체할 수 있게 한다. 비공개 베타는 5개 핵심 언어로 진행하고, 정식 글로벌 v1은 25개 언어 지원을 출시 조건으로 삼는다.

## 2. 확정된 제품 원칙

1. Friends는 언어교류와 편안한 친구 찾기가 중심이고 Dating은 별도 앱으로 분리한다.
2. 공개 출시되는 Friends와 Dating은 모두 만 18세 이상이다.
3. 청소년 서비스는 초기 범위에서 제외하고 향후 학교·기관·보호자 기반의 폐쇄형 프로그램으로만 검토한다.
4. 두 앱은 계정을 공유하지만 프로필, 관계 의도, 추천 데이터와 노출 권한은 분리한다.
5. 무작위·익명 영상채팅, 외모 인기순위, Hot-or-Not식 평가는 제공하지 않는다.
6. 모든 대화는 상호 수락 후 시작하며, 사용자가 문자에서 음성·화상으로 관계를 점진적으로 확장한다.
7. 무료 일반회원은 BYOK를 사용하고 스페셜회원은 관리형 로이·지니와 포함 통역량을 받는다.
8. 행동기반 광고와 프로필 데이터 판매에 의존하지 않는다.
9. Web3는 2단계에서 비수탁형 지갑과 승인된 스테이블코인 결제로 도입한다.
10. 자체 코인 발행, 앱 내 디지털 기능의 코인 결제 우회, ChinguMe의 고객 개인키 직접 보관은 초기 범위에서 제외한다.

## 3. 제품 구성

### 3.1 ChinguMe Friends

언어교류, 문화교류, 관심사 커뮤니티와 편안한 친구 찾기를 제공한다.

- 사용 언어와 배우고 싶은 언어 기반의 상호보완 매칭
- 음악·영화·게임·사진 등 공통 관심사 기반 추천
- 1:1 채팅, 그룹 채팅, 음성방, 영상방과 오프라인 이벤트
- Local Buddy, 여행 동행과 문화 체험
- 만 18세 이상 전용 Opportunities 탭

### 3.2 ChinguMe Dating

상호 동의한 성인의 연애·이성 만남을 위한 독립 앱이다.

- 성별, 연령, 거리, 관계 의도, 생활방식과 가치관 필터
- Friends 활동정보와 관계 의도의 자동 공유 금지
- 별도 프로필 활성화와 동의 절차
- 안전한 문자 대화 후 음성·화상으로 전환
- 금전 요구, 로맨스 스캠과 스토킹 위험 보호 강화

### 3.3 ChinguMe Opportunities

Friends 안에서 운영되는 18세 이상 글로벌 기회·업무 마켓플레이스다. 친구 프로필과 업무 프로필을 분리하고 Dating에서는 노출하지 않는다.

- Local Buddy: 비영리 여행 동행과 생활 안내
- Professional Guide: 유료 관광 안내, 출장 동행, 통역 보조
- Freelance: 개발, 디자인, 번역, 마케팅, 촬영과 영상 편집
- Casting: 사진모델, 배우, 성우, 크리에이터와 촬영 스태프
- Jobs: 정규직, 계약직, 아르바이트, 인턴과 원격근무
- Collaboration: 콘텐츠 공동제작, 스타트업과 프로젝트 파트너

## 4. 목표 사용자

### 4.1 해외 사용자

- 한국 여행 또는 체류 중 현지 친구와 안내가 필요한 성인
- 한국인 파트너와 진지한 관계를 찾는 성인
- 한국의 개발자, 제작자, 모델, 배우 또는 크리에이터와 협업하려는 의뢰인

### 4.2 한국 사용자

- 외국어와 해외문화를 자연스럽게 배우고 싶은 성인
- 외국인 친구, 여행 동행 또는 연인을 찾는 성인
- 자신의 전문기술과 포트폴리오로 글로벌 업무를 수주하려는 성인
- 해외 프로젝트 인재와 현지 파트너를 찾는 의뢰인

### 4.3 스페셜회원

- API 키 설정 없이 고품질 통역을 원하는 사용자
- 대화 문맥과 문화 차이를 세밀하게 보조받고 싶은 사용자
- 장시간 국제 음성·화상통화 또는 다국어 업무회의가 필요한 사용자

## 5. 관심사 분류체계

관심사는 `대분류 → 세부분류 → 자유 태그`의 3단계로 구성한다. 가입 시 대분류 3~5개만 필수로 받고, 세부분류는 최대 10개까지 선택하게 한다. 작품명, 가수명, 게임명과 취향은 자유 태그로 추가한다.

1. 음악: K-pop, 팝, 록, 힙합, R&B, 재즈, 클래식, EDM, 인디, 악기와 콘서트
2. 영화·드라마·애니메이션: 로맨스, 코미디, 액션, SF, 판타지, 공포, 다큐멘터리와 OTT
3. 게임: 모바일, PC, 콘솔, 보드게임, e스포츠, RPG, FPS, 전략과 시뮬레이션
4. 사진·영상·창작: 인물, 여행, 풍경, 음식, 필름카메라, 영상, 그림, 디자인과 글쓰기
5. 여행·문화: 국내·해외여행, 배낭여행, 캠핑, 역사, 전통문화와 축제
6. 음식·카페: 한식, 일식, 중식, 양식, 베이킹, 요리, 카페, 와인과 채식
7. 스포츠·건강: 헬스, 러닝, 등산, 축구, 야구, 농구, 골프, 요가와 명상
8. 책·학습: 소설, 자기계발, 인문학, 과학, 경제, 외국어와 온라인 강의
9. 패션·뷰티: 스트리트, 클래식, 빈티지, 뷰티, 향수와 스타일링
10. 기술·비즈니스: AI, 개발, 스타트업, 투자, 자동차, 디지털기기와 마케팅
11. 반려동물·자연: 강아지, 고양이, 식물, 바다, 숲과 환경보호
12. 일상·라이프스타일: 맛집, 산책, 봉사, 종교·영성, 가족과 가치관

프로필은 전체 목록보다 상대방과 겹치는 관심사를 우선 표시한다. 관심사는 매칭, 첫 대화 추천, 커뮤니티, 이벤트와 통역 전문용어 사전에 활용한다. 자동 추론한 관심사는 사용자에게 제안만 하고 동의 없이 공개하지 않는다.

## 7. 실시간 통역과 AI

### 7.1 처리 흐름

`음성 감지 → 스트리밍 음성인식 → 언어 자동감지 → 문맥 번역 → 실시간 자막 → 선택적 번역 음성`

정상 네트워크에서 자막 번역 중앙 지연시간 1.5초 이내, 번역 음성 중앙 지연시간 2.5초 이내를 제품 목표로 한다. 원문과 번역을 함께 확인할 수 있고, 사용자는 다음 통화 모드를 선택한다.

- 원음과 번역 자막
- 원음 볼륨을 낮춘 번역 음성
- 번역 음성만 듣기

### 7.2 일반회원 BYOK

- 지원 공급자: OpenAI, Google, Azure Speech, DeepL
- API 키는 KMS/HSM 기반 암호화 금고에 저장
- 단말기, 분석도구, 고객지원 화면과 오류로그에 평문 노출 금지
- 공급자 연결검사, 사용량 한도, 즉시 연결해제와 키 삭제 제공
- 잔액 부족이나 키 오류는 해당 사용자의 통역만 중단하고 원음 통화는 유지
- 공급자별 지원기능 차이를 호출 전 명확히 표시

### 7.3 Special과 로이·지니

- 로이: 빠르고 정확한 통역, 학습·업무·명확한 의사전달 중심
- 지니: 편안한 관계 형성, 감정·뉘앙스·문화 표현 중심
- 에이전트 성격, 말투, 음성, 개입 정도 조절
- 회원별 세션, 메모리, 권한과 사용량 분리
- 장기 기억은 항목별 동의, 조회, 수정과 삭제 제공
- 메시지 전송, 파일 공유, 결제와 약속 등록은 사용자 확인 없이 실행 금지
- 상대방에게 AI 에이전트 사용 여부 표시

OpenClaw는 범용 실시간 음성 엔진이 아니라 대화 코파일럿으로 사용한다. ASR·번역·TTS는 전용 저지연 파이프라인이 담당하고 OpenClaw는 문맥, 말투, 문화설명, 요약과 허용된 기억을 제공한다.

### 7.4 미디어 통역

- 문자메시지 자동번역과 원문 확인
- 음성메시지 자막과 번역 음성
- 이미지 OCR과 번역
- PDF·문서 구조를 유지한 번역과 요약
- 동영상 자막 생성, 번역과 검색
- 화상통화 실시간 자막과 선택적 더빙
- 화면 공유 중 선택영역 텍스트 번역

## 8. 통신과 미디어

### 8.1 문자와 그룹 대화

- 1:1·그룹·커뮤니티 채팅
- 답장, 인용, 리액션, 멘션, 고정메시지
- 읽음 상태, 예약전송, 수정과 회수
- 연락처·개인정보·계좌번호 전송 경고
- 욕설·사기·위험 표현 감지와 신고 연결

### 8.2 음성·화상통화

- 1:1 및 그룹 음성·화상통화
- 카메라·마이크 전환, 배경 흐림, 소음 제거
- 화면 공유, 가상 배경, 손들기와 리액션
- 네트워크 상태에 따른 화질·음질 자동 조절
- 통화 중 언어와 통역 모드 변경
- 통화 중 긴급 종료·차단·신고

### 8.3 파일·이미지·영상

- 사진, GIF, 짧은 영상, 음성메시지, 문서와 압축파일
- 대용량 업로드 재개, 만료 링크와 다운로드 권한
- 악성코드, 위험 확장자, 유해 콘텐츠와 개인정보 노출 검사
- 실행파일과 정책상 위험한 파일 차단
- 원본 화질 전송과 데이터 절약 모드
- 위치정보 등 불필요한 메타데이터 제거 옵션

### 8.4 개인정보 보호 모드

AI 통역 모드에서는 필요한 음성·텍스트만 암호화된 경로로 AI에 전달한다. 원본 음성은 기본적으로 저장하지 않고 실시간 처리 후 폐기한다. 사용 공급자와 처리범위를 통화 전에 고지하며 녹음·요약·장기 기억은 참여자 모두의 별도 동의를 요구한다.

비공개 통화 모드는 종단간 암호화를 제공한다. 서버 기반 AI 통역, 녹음과 콘텐츠 검사는 사용할 수 없음을 명확히 알린다. 향후 자체 온디바이스 모델이 준비되면 제한적인 로컬 통역을 제공한다.

개인정보, 결제원장과 신고증거는 일반 콘텐츠와 저장영역, 암호화키, 접근권한과 보존정책을 분리한다.

### 14.4 미디어와 AI 공급자 추상화

- 1단계는 관리형 WebRTC SFU·TURN과 미디어 인프라 사용
- 앱은 공급자 SDK에 직접 종속되지 않고 ChinguMe Media API를 사용
- Translation Orchestrator가 공급자 어댑터를 선택
- 언어, 지연, 품질, 비용과 장애상태에 따라 자동 라우팅
- 공급자 장애 시 원음 통화 유지 → 번역지연 안내 → 텍스트 번역 순으로 성능 저하
- 모든 미디어·번역 요청은 공통 세션 ID로 품질, 지연과 비용을 추적

### 14.5 관리형 OpenClaw

- ChinguMe가 관리하는 Gateway
- 회원별 세션, 메모리, 사용량과 권한 분리
- 통역, 요약과 문화설명 도구만 기본 허용
- 임의 파일시스템, 외부 메시지 전송, 무제한 웹접속과 결제도구 차단
- 사용자 확인이 필요한 행동은 명시적 승인 후 실행
- Gateway 인증정보를 모바일 사용자와 에이전트 응답에 노출하지 않음

### 14.6 자체화 경로

1. 관리형 미디어·AI로 출시하고 실제 품질과 원가 측정
2. 고비용 언어·지역부터 자체 ASR·번역·TTS 도입
3. 지역별 자체 SFU·TURN 노드 운영
4. 자체 모델을 기본으로 하고 외부 공급자를 장애 대체로 유지

도메인 모델, 세션 ID, 사용자 권한, 품질지표와 공급자 인터페이스를 ChinguMe가 소유하여 실행 계층을 바꿔도 앱과 핵심 업무를 다시 작성하지 않게 한다.

## 21. 검증 전략

- 단위시험: 매칭 규칙, 권한, 요금과 상태전이
- 계약시험: 미디어, 번역, 신원확인, 결제와 지갑 공급자
- 통합시험: 가입→매칭→통역통화→신고와 공고→계약→정산
- 언어시험: 25개 언어 정확도, 지연, 고유명사, 존댓말, 유해표현과 문화적 의미
- 성능시험: 불안정 모바일 네트워크, 동시통화, 파일 업로드와 대량번역
- 보안시험: 계정탈취, 키 유출, 권한상승, 악성파일, 지갑과 OpenClaw
- 안전 레드팀: 사칭, 로맨스 스캠, 성적 착취, 불법구인과 신고회피
- 복구시험: 공급자 장애, 지역중단, 메시지·결제 데이터 복구

## 22. 글로벌 v1 완료 조건

1. Friends와 Dating의 18세 이상 인증·분리된 추천·상호수락 흐름이 동작한다.
2. 5개 핵심 언어에서 문자, 음성, 화상과 주요 미디어 통역 품질목표를 충족한다.
3. 나머지 20개 언어의 실제 기능범위와 품질등급이 검증돼 사용자에게 정확히 표시된다.
4. 일반회원 BYOK와 Special 로이·지니가 서로 분리된 과금·권한으로 동작한다.
5. AI 통역 모드와 종단간 암호화 비공개 모드의 차이를 통화 전에 고지한다.
6. 신고, 차단, 증거격리, 이의제기와 24시간 긴급대응 절차가 운영된다.
7. Opportunities 공고·지원·번역채팅·화상인터뷰와 안전정책이 동작한다.
8. 디지털 결제와 사람 간 서비스 결제가 회계·앱마켓·권한상 분리된다.
9. 공급자 장애 시 원음 통화와 단계적 성능저하가 검증된다.
10. 국가별 법률·앱마켓·개인정보·결제 출시 체크리스트가 승인된 국가만 공개된다.
