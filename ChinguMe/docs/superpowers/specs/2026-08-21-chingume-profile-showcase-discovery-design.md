# ChinguMe 프로필 쇼케이스·검색·쇼츠 탐색 설계서

- 문서 상태: 사용자 승인 설계
- 작성일: 2026-08-21
- 대상 제품: ChinguMe Friends, ChinguMe Dating, ChinguMe Opportunities
- 상위 문서: `docs/superpowers/specs/2026-08-21-chingume-global-platform-design.md`

## 1. 목표

사용자가 이미지와 15~60초 세로형 자기소개 영상으로 자신을 표현하고, 다른 사용자가 검색형 탐색과 쇼츠형 탐색 중 원하는 방식을 동등하게 이용해 프로필을 발견한 뒤 안전하게 채팅을 신청할 수 있게 한다.

검색과 쇼츠는 서로 다른 프로필 풀이 아니라 동일한 공개 가능 쇼케이스를 서로 다른 방식으로 보여준다. 노출은 외모·인기 경쟁이 아니라 언어, 관심사, 활동목적, 지역 범위, 활동시간과 안전 적합도를 기준으로 한다.

## 2. 확정된 원칙

1. 앱의 탐색 영역에 `검색`과 `쇼츠`를 동등한 1차 탭으로 제공한다.
2. Friends, Dating, Opportunities 쇼케이스는 별도 프로필·인덱스·노출권한·추천 신호를 사용한다.
3. 쇼츠를 보지 않는 사용자는 검색만으로 모든 핵심 발견·채팅 신청 기능을 이용할 수 있다.
4. 상대의 전체 프로필과 공통점·추천 이유를 확인한 후 채팅을 신청한다.
5. 상대방이 수락하기 전에는 문자, 파일, 음성·화상통화가 열리지 않는다.
6. 외모점수, Hot-or-Not 평가, 공개 좋아요 수, 인기순위와 유료 인기점수 판매를 제공하지 않는다.
7. 자동재생, 소리, 데이터 사용과 개인화는 사용자가 제어한다.
8. 이미지·영상은 공개 전에 악성파일·성적 콘텐츠·사칭·개인정보 노출 검사를 통과해야 한다.
9. 자동 자막·번역은 원문과 함께 제공하고 실제 지원 언어·모달리티를 정확하게 표시한다.
10. 정확한 위치, 연락처와 원본 미디어 메타데이터는 기본적으로 공개하지 않는다.

## 3. 프로필 쇼케이스 구성

### 3.1 공통 미디어

- 대표 이미지 1장
- 추가 이미지 최대 6장
- 세로형 자기소개 영상 최대 1개
- 영상 길이 15~60초
- 서버가 생성한 안전한 썸네일과 스트리밍 파생본
- 자동 생성 원문 자막과 사용자가 승인한 수정 자막
- 지원되는 대상 언어별 번역 자막

동영상이 없는 사용자도 이미지와 텍스트만으로 검색·추천·채팅 신청 대상이 될 수 있다. 영상 업로드가 매칭의 필수조건이나 유료 노출의 전제가 되지 않는다.

### 3.2 영역별 내용

Friends 쇼케이스는 사용언어·학습언어, 관심사, 문화교류 목적, 함께 하고 싶은 활동을 중심으로 한다. Dating 쇼케이스는 별도 활성화와 동의 아래 관계 의도, 가치관과 생활방식을 중심으로 하며 Friends 영상·문구를 자동 복사하거나 공개하지 않는다.

Opportunities 쇼케이스는 Friends 안의 업무 프로필에서 관리한다. 기술, 경력, 포트폴리오, 작업방식과 제공 가능한 서비스만 포함하며 캐주얼 Friends 또는 Dating 자기소개를 노출하지 않는다. 모델·배우·크리에이터는 일반 자기소개와 별도로 권리·사용범위가 명확한 포트폴리오 미디어를 선택한다.

### 3.3 상태와 공개범위

쇼케이스 상태는 `draft → processing → moderation_pending → published` 또는 `rejected|paused|archived`로 관리한다. 처리 또는 검사가 완료되지 않은 미디어는 검색·쇼츠·공유 링크에 노출하지 않는다.

공개범위는 영역별로 다음을 지원한다.

- 추천·검색·쇼츠에 공개
- 추천과 검색에만 공개하고 쇼츠 제외
- 기존 연결회원에게만 공개
- 비공개

사용자는 쇼츠 노출만 끄면서 검색 프로필은 유지할 수 있다. Dating 비활성화는 Dating 쇼케이스와 인덱스를 즉시 제거하지만 Friends와 Opportunities에는 영향을 주지 않는다.

## 4. 탐색 경험

### 4.1 검색 탭

검색은 다음 조건을 조합한다.

- 국가와 안전한 지역 범위
- 사용언어와 학습언어
- 관심사 대분류·세부분류·승인된 자유태그
- Friends 활동목적 또는 Dating 관계 의도
- 활동 가능한 요일·시간대
- 연령 범위와 거리 범위 등 영역별 허용조건
- 프로필·업무 인증수준
- Opportunities의 기술, 경력, 예산, 일정, 원격·현장 조건

결과는 이미지 중심 카드와 간단한 공통점, 지원언어, 활동목적, 추천 이유를 표시한다. 정확한 거리, 거절·신고이력, 내부 안전점수와 민감한 필터조건은 공개하지 않는다.

### 4.2 쇼츠 탭

쇼츠는 한 화면에 한 자기소개 영상을 표시하고 다음 동작을 제공한다.

- 재생·일시정지·음소거
- 원문 자막·번역 자막 전환
- 데이터 절약 화질
- 전체 프로필 열기
- 관심 없음
- 숨기기·차단·신고
- 채팅 신청

운영체제 접근성 설정, 앱의 자동재생 설정과 데이터 절약 모드를 존중한다. 기본 음소거와 수동 소리 켜기를 사용하며, 셀룰러 환경에서는 사용자가 허용하지 않은 고화질 선로딩을 하지 않는다.

### 4.3 동등성

검색과 쇼츠는 동일한 권한·차단·표면분리·안전 필터를 적용한다. 두 탭은 독립적인 탐색 이력과 `관심 없음` 피드백을 저장할 수 있지만, 차단·거절·비노출은 양쪽에 즉시 적용한다.

검색만 사용하는 사용자가 쇼츠 사용자보다 채팅 신청, 추천 품질, 프로필 상세정보 또는 안전기능에서 불리하지 않게 한다.

## 5. 노출과 정렬

후보 생성 단계에서 다음 대상을 먼저 제외한다.

- 차단 또는 거절한 관계
- 이미 활성 연결인 상대
- 비활성·일시정지·제재·심사 중 프로필
- 다른 제품 영역의 프로필
- 상호 하드필터가 맞지 않는 Dating 후보
- 국가·연령·안전·법률상 노출 불가 후보
- 쇼츠 비공개 사용자의 영상

남은 후보는 언어 상호보완, 승인된 관심사 중복, 활동목적 적합도, 활동시간, 안전한 지역 범위, 최근 정상활동과 노출 다양성으로 정렬한다. 쇼츠 완주율·프로필 열기·관심 없음은 해당 사용자의 개인화에 제한적으로 사용하지만 공개 인기도나 외모 선호점수로 변환하지 않는다.

같은 창작자 또는 특정 국가·외형 집단의 반복노출을 제한하고, 신규 사용자에게 공정한 탐색 기회를 제공한다. 유료 상품은 검색조건에 맞지 않는 사람을 강제로 노출하거나 안전 제외를 우회할 수 없다.

## 6. 채팅 신청과 수락

사용자는 검색 카드, 전체 프로필 또는 쇼츠에서 채팅을 신청할 수 있다. 신청 화면은 다음을 포함한다.

- 짧은 인사말
- Friends의 교류 목적, Dating의 대화 의도 또는 Opportunities의 업무 목적
- 상대와 겹치는 관심사·언어 중 선택 가능한 대화 시작 주제
- 상대방 언어로 번역한 미리보기와 원문

Friends와 Dating의 신청은 Plan 2의 영역별 관계 상태를 사용해 `pending`으로 생성한다. 수신자는 프로필과 신청내용을 확인한 뒤 `수락|거절|차단·신고`를 선택한다. 수락하면 같은 영역의 대화방 하나를 생성한다. 거절하면 해당 영역의 추천·검색·쇼츠에서 다시 노출하지 않으며, 요청자는 거절 사유나 수신자의 활동상태를 알 수 없다.

Opportunities의 신청은 소셜 관계를 만들지 않는다. Plan 7의 `업무 문의|공고 지원` 상태와 목적 한정 대화방을 사용하고, 공고·업무 프로필·예산·일정 참조를 유지한다. 업무 문의를 수락해도 Friends 또는 Dating 연결·추천 데이터에는 반영하지 않는다.

신청 남발은 회원·기기·네트워크 위험신호와 시간창별 제한을 적용한다. 복사한 동일문구 대량전송, 연락처·계좌·투자 권유가 포함된 첫 신청은 경고·제한·검토 대상으로 보낸다.

## 7. 미디어 처리와 자동번역

1. 단말에서 길이·형식·용량을 사전검사하고 업로드 예약을 요청한다.
2. 원본을 격리 저장하고 서버 관측 MIME·크기·해시를 검증한다.
3. 악성파일과 유해 콘텐츠를 검사한다.
4. 위치 등 불필요한 메타데이터를 제거한 파생 이미지를 생성한다.
5. 세로형 스트리밍 영상, 썸네일과 저화질 파생본을 생성한다.
6. 음성인식으로 원문 자막을 만들고 사용자가 검토·수정할 수 있게 한다.
7. 지원되는 언어에 번역 자막을 생성하고 원문 전환을 제공한다.
8. 모든 검사와 처리 완료 후 영역별 검색·쇼츠 인덱스에 게시한다.

ASR·번역 실패는 영상 게시 자체를 무조건 막지 않는다. 해당 기능을 `자막 처리 실패` 또는 `번역 미지원`으로 정확히 표시하고 원본 영상·사용자 작성 자막으로 게시할 수 있다. 유해 콘텐츠 또는 파일 안전검사 실패는 게시를 막고 재검토·이의제기 경로를 제공한다.

## 8. 안전과 개인정보

- 만 18세 이상 인증 사용자만 게시·탐색·채팅 신청 가능
- 얼굴·신분·성별·민감특성을 영상에서 자동 추론해 공개 프로필에 추가하지 않음
- 정확한 GPS, 촬영장소, 기기정보와 연락처 메타데이터 제거
- 전화번호, 계좌번호, 외부 메신저 ID와 주소 노출 경고·마스킹
- 프로필·영상에서 두 동작 이내 신고와 즉시 차단
- 차단 즉시 검색·쇼츠·프로필·신청함·추천·캐시에서 상호 비노출
- 성적 콘텐츠, 사칭, 불법촬영, 스토킹, 폭력위협과 미성년자 의심에 대한 검토 큐
- 원본·파생본·자막·검사결과의 영역별 보존·삭제 전파
- 운영자 원본 열람은 역할, 사유, 사건번호와 감사로그 필요

삭제 또는 공개중지 요청은 새 노출을 즉시 막고 CDN·검색·쇼츠 캐시를 무효화한다. 법적 보존이 필요한 신고증거는 일반 프로필 저장소와 분리해 제한적으로 보존한다.

## 9. 주요 도메인과 인터페이스

```text
ProfileShowcase
- showcaseId, memberId, surface
- headline, introduction, languages, interestIds, purpose
- heroImageId, galleryMediaIds, introVideoId
- visibility, shortsEligible, moderationState, publishedAt, version

ShowcaseDiscoveryQuery
- surface, mode(search|shorts), viewerId
- languageFilters, interestFilters, purposeFilters
- country, regionBand, activeTime, cursor

ChatRequest
- requestId, requesterId, recipientId, surface
- kind(social_connection|opportunity_inquiry|opportunity_application)
- showcaseVersion, greetingOriginal, greetingTranslation
- purpose, conversationStarter, state, createdAt
```

외부 API는 `surface`를 요청 본문에서 임의로 신뢰하지 않고 Friends·Dating의 인증된 라우트와 프로필 활성상태로 결정한다. 쇼츠 조회 이벤트는 최소화한 목적별 분석 이벤트로 수집하고 원본 미디어·자막·민감 프로필 정보를 분석도구에 전송하지 않는다.

## 10. 오류와 성능저하

- 동영상 처리 지연: 이미지·텍스트 프로필을 먼저 게시하고 영상은 처리상태 표시
- 자막·번역 실패: 원문 또는 사용자 작성 자막 유지, 미지원 상태 표시
- 쇼츠 서비스 장애: 검색 탭과 프로필·채팅 신청 유지
- 검색 서비스 장애: 최근 안전한 추천 캐시 또는 쇼츠 제공, 모든 차단·노출권한은 원본 서비스에서 재검사
- CDN 장애: 썸네일·텍스트 카드로 성능저하
- 안전검사 장애: 신규 미디어는 격리 유지, 기존 승인 콘텐츠만 노출
- 채팅 신청 경합: 멱등키와 한 쌍·영역당 하나의 활성 관계 제약으로 중복 방지

## 11. 검증과 완료조건

- Friends·Dating·Opportunities 쇼케이스 데이터가 API·DB·검색·캐시에서 교차 노출되지 않는다.
- 검색과 쇼츠가 동일한 차단·거절·안전 제외결과를 만든다.
- 쇼츠 비공개 사용자는 검색에는 노출되지만 쇼츠에는 노출되지 않는다.
- 검색만 사용하는 사용자가 전체 프로필 확인과 채팅 신청·수락을 완료할 수 있다.
- 15초 미만·60초 초과, 위험 MIME, 악성·유해 미디어와 위치 메타데이터 정책을 검증한다.
- 자동 자막·번역의 원문 전환, 처리실패와 미지원 상태가 정확히 표시된다.
- 거절·차단 후 검색·쇼츠·캐시·신청함에서 재노출되지 않는다.
